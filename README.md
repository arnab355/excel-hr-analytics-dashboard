# Excel HR Analytics Dashboard

An interactive and comprehensive HR dashboard built in Microsoft Excel to analyze workforce metrics, employee demographics, compensation spread, and job satisfaction. 

---

## Project Overview
Managing workforce data effectively is crucial for modern human resources management. This project processes a dataset of **1,470 employees** to deliver actionable insights into employee distribution, salary structures, tenure spread, and workplace well-being. 

The entire solution is built using native Excel tools—including **Pivot Tables, Pivot Charts, Custom Calculated Fields, and Interactive Slicers**—providing stakeholders with a clean, executive-level interface.

---

## Key Metrics & Features Visualized
* **Headcount & Payroll KPIs:** Track total active employees and aggregate monthly salary expenditure.
* **Employee Demographics:** Gender distribution breakdown and education level percentages (Bachelor, Master, College, etc.)[cite: 1].
* **Employee Well-being:** Visualizing job satisfaction levels and work-life balance ratings across departments[cite: 1].
* **Tenure & Salary Analysis:** Analyzing salary spreads across working years for full-time employees and contractors[cite: 1].
* **Monthly Salary Trends:** Line chart tracking hiring and salary movement over time[cite: 1].
* **Interactive Filtering:** Fully connected Slicers for **Department** and **Job Role** allowing instant cross-filtering across all charts.

## Dataset Details
* **Records:** 1,470 employee entries
* **Key Fields Used:** `ID_employe`, `Department`, `Job Role`, `Gender`, `Education`, `JobSatisfaction`, `WorkLifeBalance`, `Salary`, `TotalWorkingYears`, `EmploymentType`, `DateStart`.

---

## Tools & Techniques Used
* **Microsoft Excel**
* **Pivot Tables & Pivot Charts** for dynamic data aggregation
* **Data Grouping** (Grouping dates by Months/Years)
* **Value Field Settings** (Converting raw counts to % of Grand Total)
* **Report Connections (Slicers)** for synchronized multi-chart filtering
